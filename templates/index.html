🛠️ Инструкция по развертыванию

Пошаговое руководство для подключения Supabase и деплоя на Render

Шаг 1

⚡ Настройка Supabase

  1. Перейдите на supabase.com и создайте новый проект.
  2. В левом меню откройте SQL Editor -> New Query.
  3. Вставьте код из файла supabase_schema.sql и нажмите Run.
  4. Перейдите в Project Settings -> API и скопируйте:
    • Project URL
    • anon public key
Шаг 2

🚀 Деплой на Render

  1. Зайдите на render.com и выберите New + -> Web Service.
  2. Подключите GitHub репозиторий проекта.
  3. Укажите параметры:
    • Runtime: Python 3
    • Build Command: pip install -r requirements.txt
    • Start Command: gunicorn app:app
  4. В разделе Environment Variables добавьте переменные:
    • SUPABASE_URL
    • SUPABASE_KEY
  5. Нажмите Create Web Service! 🚀
Шаг 3

🐙 GitHub & Auto-Deploy

  1. Репозиторий уже настроен и запушен на ваш GitHub.
  2. Каждый git push автоматически инициирует сборку и деплой на Render.
  3. Файл render.yaml в репозитории позволяет развернуть проект в 1 клик через Blueprint!
